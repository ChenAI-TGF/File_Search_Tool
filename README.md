# File_Search_Tool


## English Documentation

File_Search_Tool is a powerful file intelligent search tool that helps you quickly find files on your computer. Whether searching by file name or file content, this tool can efficiently complete the task and supports multiple file type filtering.

### Features

- Support searching by file name or file content
- Provide multiple file type category filtering (audio, video, image, document, etc.)
- Allow adding custom file types
- Multi-process search for improved efficiency
- Real-time display of search progress and statistics
- Highlight matching content in search results
- User-friendly graphical interface

### Interface Display

![Main Interface](screenshots\main_window.png)

### Installation and Usage

1. Ensure Python 3.x is installed on your system
2. No additional libraries required, using Python standard libraries
3. Download the project code
4. Run the main program: `python main.py`
5. Usage steps:
   - Select the search path
   - Enter search keywords
   - Choose search type (file name or content)
   - Check the file types to search
   - Click the "Start Search" button

### Notes

- Searching large files or a large number of files may take a long time
- Content search is mainly for text files and has limited effect on binary files (such as images, videos)
- Multi-process search will occupy more system resources and may affect the operation of other programs

### 安装与使用

1. 确保您的系统已安装Python 3.x
2. 无需额外安装依赖库，使用Python标准库
